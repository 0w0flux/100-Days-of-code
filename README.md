## About This Repository

This repository documents my progression through the **100 Days of Code** course by Dr. Angela Yu.

The goal is to learn how to code, explore new concepts, gain different perspectives and apply what I learned directly into projects.

I mainly learn through Dr. Angela Yu's explanations and exercises, while occasionally using AI to get another viewpoint, better understand concepts, or help with debugging. 

Throughout the days, the projects gradually become more complex and combine more and more Python concepts.

---

## Goals

During this challenge, I want to:

- Improve my coding skills
- Strengthen my problem-solving abilities
- Learn how to plan, structure, and implement programs and systems effectively
- Write cleaner and more structured code
- Build larger projects independently
- Document my progress
